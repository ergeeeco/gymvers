# Железный круг: как выложить бесплатно

Приложение состоит из статической страницы (index.html) и бесплатного сервиса Supabase. Он даёт регистрацию, базу данных и хранилище фото и видео.

## 1. База данных и регистрация (Supabase)
1. Зарегистрируйтесь на supabase.com и создайте проект (тариф Free).
2. Откройте SQL Editor, вставьте весь файл schema.sql и нажмите Run. Появятся таблицы, права доступа и хранилище media.
3. Authentication → Providers → Email. Для быстрого старта отключите «Confirm email», тогда регистрация сработает сразу. Если оставить включённым, пользователям придёт письмо с подтверждением.
4. Project Settings → API. Скопируйте Project URL и anon public key.
5. Вставьте их в блок CFG в начале скрипта в index.html. Ключ anon можно публиковать: данные защищены правилами доступа из schema.sql.

## 2. Размещение сайта (любой из бесплатных вариантов)
- Cloudflare Pages: Workers & Pages → Create → Pages → Upload assets, загрузите index.html. Адрес вида имя.pages.dev.
- Netlify Drop: перетащите папку на app.netlify.com/drop.
- GitHub Pages: загрузите index.html в репозиторий, Settings → Pages.

## 3. Проверка
Откройте адрес сайта, зарегистрируйтесь, внесите результаты, опубликуйте тренировку с фото. Данные сохраняются в базе.

## Ограничения бесплатного уровня (проверьте актуальные условия на сайтах сервисов)
- У Supabase Free ограничены размер базы и хранилища (порядка сотен МБ и 1 ГБ), а проект могут приостановить после недели без активности. Его можно снова включить в панели.
- Приложение загружает все профили и последние 300 постов целиком. Для сотен активных пользователей понадобится постраничная загрузка.
- Платить придётся, когда вырастет объём видео. Тогда можно подключить отдельное хранилище или сжимать видео перед загрузкой.
- Свой домен (например, ironcircle.ru) стоит около нескольких сотен рублей в год. Бесплатный адрес pages.dev работает без него.
